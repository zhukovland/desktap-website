Changelog

What's new in Desktap Agent

Every release of the Desktap agent for Mac, newest first. Since 1.2.0 the agent updates itself: a new version shows up as Update Available in its window.

Download Mac AgentSend link to Mac

Free macOS 15+ Notarized by Apple

  1. 1.2.3

    Sep 22, 2026 Latest

    Faster live widgets, a sharper AI

    • NewThree new tools for your AI: get_page_layout shows a page and where there is room, get_startup_script_status tells why a live button stopped, and restart_startup_script starts it again.
    • NewYour AI can move and resize the buttons you already have. It knows whether an iPhone or an iPad is connected, so with an iPhone it never puts a button in the columns only an iPad shows.
    • ImprovedLive widgets update faster and cost your Mac less. A script can tell when its button is off screen and take a break.
    • ImprovedYour AI tells “you rejected it” from “accepted, but the spot was taken”, and never sends buttons blind when it can’t read your deck.
    • FixedScripts left behind when the agent quit unexpectedly are cleaned up, so a live widget never runs twice. A failed script shows its own error message.

  2. 1.2.2

    Sep 20, 2026 Latest

    Any AI app, one click

    • NewClaude Code and ChatGPT / Codex join Claude Desktop: connect any of them in one click. The agent lists only the ones on your Mac.
    • NewThe widget skill for Claude Code and ChatGPT / Codex teaches your assistant to draw good live widgets. One click installs it.
    • Newrender_preview: your AI sees an SVG face, and how it glides into the next frame, before anything reaches your phone.
    • ImprovedEvery connected assistant gets short guidance from the agent: look at your deck first, preview before sending.
    • FixedCodex keeps its connection to Desktap and no longer asks you to approve tools that only read.

  3. 1.2.1

    Sep 20, 2026 Latest

    SVG faces

    • NewA button can wear a drawn SVG face for good, not only frames from a live script. Your AI can set one when it creates or updates a button.
    • ImprovedGradients, clipping, fill rules and more color formats: icons exported from Figma, Sketch or Illustrator draw as designed.

  4. 1.2.0

    Sep 17, 2026 Latest

    Updates itself; live SVG widgets

    • NewAutomatic updates. The agent looks for a new version once a day and offers it as Update Available in its window. Install 1.2.0 by hand once; later versions come by themselves.
    • NewLive SVG widgets: a startup script can draw the whole button (a ring, a gauge, a chart), and the face glides from one update to the next.
    • ImprovedStartup scripts keep retrying instead of giving up after five failures. A script with a #! line runs with that interpreter: python3, bash and others.
    • ImprovedTaps stay instant with many live scripts running.
    • ImprovedA new drag-to-Applications installer. In Applications the file is now “Desktap Agent.app” rather than “DesktapAgent.app”.
    • FixedFewer requests for the pairing code after switching macOS accounts, and live buttons no longer miss their first update after a switch.

  5. 1.1.2

    Sep 5, 2026 Latest

    Bluetooth and pairing fixes

    • FixedScripts that use Bluetooth (say, blueutil to connect headphones) get the macOS permission prompt instead of a silent refusal.
    • FixedEach macOS account on the Mac keeps its own pairing, so switching accounts no longer asks for the code again.

  6. 1.1.1

    Aug 28, 2026 Latest

    Richer notification actions

    • ImprovedYour AI can put any command type on a notification’s action buttons: a shortcut, a keystroke, a system action, AppleScript, a text snippet and more.

  7. 1.1.0

    Aug 28, 2026 Latest

    Live buttons and notifications

    • NewStartup scripts: a button can run a script that starts when your phone connects and keeps the button current. The agent restarts a script that fails; Running Scripts shows its state, with Restart.
    • NewNotifications: a script can notify your iPhone, your Mac or both, with up to four action buttons that run commands. Notifications for the phone wait while it is away.
    • NewSeveral macOS accounts on one Mac: the account in front serves your phone, the others pause.
    • ImprovedYour AI knows startup scripts and notifications and can write them for you.
    • ChangedA tap or long-press script now stops after 60 seconds. Anything longer belongs in a startup script.

  8. 1.0.0

    Jun 21, 2026 Latest

    First release

    • NewPairs with Desktap on iPhone and iPad over your Wi-Fi with a one-time code, then runs what the buttons ask for: keyboard shortcuts, system actions, apps, URLs, AppleScript, Shortcuts and shell scripts.
    • NewLives in the menu bar: trusted devices, running scripts with Stop, Launch at Login, and help with the Accessibility and Automation permissions.
    • NewA built-in MCP server: one click connects Claude Desktop, and Connect Other MCP Clients gives the config for any other MCP tool. Your AI builds profiles, pages and buttons; nothing changes on your phone until you accept.
    • NewIf you allow it, your AI can run a command to look around your Mac (run_probe), each one approved on your iPhone or iPad.

Every version is also on GitHub Releases.
